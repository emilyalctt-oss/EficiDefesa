
# Base Técnica BCCI v2.2

A base técnica foi consolidada para apoiar apenas o escopo atual do EficiAgro: análise energética, econômica e operacional de sistemas de irrigação já instalados em cafeicultura.

## Princípios
- cada parâmetro possui unidade, aplicação, referência e limitação;
- valores agronômicos são contextuais e não entram automaticamente no cálculo energético;
- tarifa e desconto são informados pelo usuário;
- indicadores por hectare são comparativos, não benchmarks universais;
- recomendações são triagem técnica e não substituem inspeção ou projeto.
